# Logs locais

Dezoito logs históricos de execução do Reflex foram movidos da raiz para esta pasta sem alterar seu conteúdo. Seis continuam na raiz porque instâncias Reflex em execução mantêm esses arquivos abertos; movê-los agora poderia interferir nos processos. Após encerrar essas instâncias, eles podem ser movidos para cá. São artefatos de depuração, não entradas do aplicativo.
